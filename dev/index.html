    INSTALL

    Installation #

    The package lives in the private repository pinnjax/PINN-JAX under the pinnjax organization. Upon request, and necessity, you will be invited to the organization with read-only access.

    Accept the GitHub invitation and confirm you can open pinnjax/PINN-JAX in the browser before you install.

    Note: If you require functionality from the dev branch append @dev to the end of the install string.

    HTTPS#

    The first time you use Git against GitHub, your system may open a browser or prompt you to sign in.

    Linux / macOS:

    uv venv --python 3.13
source .venv/bin/activate
uv pip install "git+https://github.com/pinnjax/PINN-JAX.git"

    Windows (PowerShell or your IDE terminal):

    uv venv --python 3.13
.\.venv\Scripts\Activate.ps1
uv pip install "git+https://github.com/pinnjax/PINN-JAX.git"

    SSH#

    Requires an SSH key added to your GitHub account.

    Linux / macOS:

    uv venv --python 3.13
source .venv/bin/activate
uv pip install "git+ssh://git@github.com/pinnjax/PINN-JAX.git"

    Windows:

    uv venv --python 3.13
.\.venv\Scripts\Activate.ps1
uv pip install "git+ssh://git@github.com/pinnjax/PINN-JAX.git@dev"

    Windows: install uv#

    uv is not the only package manager, but it is recommended.

    If you do not have uv yet, in PowerShell:

    winget install --id=astral-sh.uv -e

    Then run the HTTPS or SSH block above.

    The current default branch and all declared dependencies are installed.
