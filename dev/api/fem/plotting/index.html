    Plotting

    Plot finite-element meshes and stress fields.

    plot_mesh draws a Tatva mesh. plot_stress reduces a stress tensor to one scalar component and passes it to plot_mesh.

    Plot a Tatva mesh and an optional scalar field on its exterior.

    The mesh is converted to a surface and drawn with Matplotlib or PyVista. Point values are stored on the nodes. Cell values are stored on the volume cells, and each exterior face then shows its parent cell. When surface_elements is given, the field is drawn only on those faces and the rest of the exterior is drawn in the default surface color.

    A 3D Matplotlib plot uses flat face colors. Point values are averaged onto each face. A 2D Matplotlib plot with point values uses Gouraud shading, and quads are split into two triangles for that path. PyVista keeps the point or cell data on the extracted surface.

    Matplotlib adds a colorbar only when it created the figure. PyVista adds its own scalar bar whenever values are present. A wireframe is drawn with no face color.

    def plot_mesh(
    mesh: Mesh,
    *,
    cell_type: CellType,
    backend: Backend = "matplotlib",
    values=None,
    data_location: DataLocation | None = None,
    surface_elements=None,
    label: str = "values",
    title: str | None = None,
    ax=None,
    plotter=None,
    dimensionality: Literal["3D", "2D"] = "3D",
    plane: Plane = "xy",
    cmap: str = DEFAULT_CMAP,
    norm=None,
    boundaries: Sequence[float] | None = None,
    show_edges: bool = False,
    lighting: bool | None = None,
    wireframe: bool = False,
    show: bool = True,
    save: bool = False,
    save_location: str | Path | None = None,
    save_name: str | None = "mesh",
    save_format: str = "pdf",
    dpi: int = 300,
):
    """Plot a Tatva mesh and an optional scalar field on its exterior.

    The mesh is converted to a surface and drawn with Matplotlib or PyVista.
    Point values are stored on the nodes. Cell values are stored on the volume
    cells, and each exterior face then shows its parent cell. When
    ``surface_elements`` is given, the field is drawn only on those faces and
    the rest of the exterior is drawn in the default surface color.

    A 3D Matplotlib plot uses flat face colors. Point values are averaged onto
    each face. A 2D Matplotlib plot with point values uses Gouraud shading, and
    quads are split into two triangles for that path. PyVista keeps the point
    or cell data on the extracted surface.

    Matplotlib adds a colorbar only when it created the figure. PyVista adds
    its own scalar bar whenever values are present. A wireframe is drawn with
    no face color.

    Args:
        mesh: Tatva mesh to draw.
        cell_type: Cell shape of ``mesh``. One of ``"triangle"``, ``"quad"``,
            ``"tetra"``, or ``"hexahedron"``.
        backend: ``"matplotlib"`` or ``"pyvista"``. The check is
            case-insensitive. Default: ``"matplotlib"``.
        values: Scalar field. One value per node when ``data_location`` is
            ``"point"``, or one value per volume cell when it is ``"cell"``.
            Omit it to draw the geometry only.
        data_location: ``"point"`` or ``"cell"``. Required when ``values`` is
            given.
        surface_elements: Exterior faces that receive ``values``. Each face is
            a sequence of node indices. Winding order does not matter. Omit it
            to color the whole exterior.
        label: Name of the scalar field, used for the colorbar. Default:
            ``"values"``.
        title: Figure title. Omit it to leave the title unset.
        ax: Matplotlib axes to draw on. A new figure is created when omitted.
            Used when ``backend`` is ``"matplotlib"``. A 3D plot requires 3D
            axes.
        plotter: PyVista plotter to draw on. A new plotter is created when
            omitted. Used when ``backend`` is ``"pyvista"``.
        dimensionality: ``"3D"``, or ``"2D"`` to project onto ``plane``.
            Default: ``"3D"``.
        plane: Projection plane for a 2D plot. One of ``"xy"``, ``"xz"``, or
            ``"yz"``. Default: ``"xy"``.
        cmap: Colormap name. Default: ``"managua"``.
        norm: Matplotlib normalization. When given, ``boundaries`` is not used.
            For PyVista, ``norm.vmin`` and ``norm.vmax`` set the color limits
            when both are present.
        boundaries: Levels for a Matplotlib ``BoundaryNorm``. For PyVista, the
            first and last entries set the color limits.
        show_edges: Draw element edges. Default: ``False``.
        lighting: PyVista lighting flag. ``None`` leaves the plotter default.
            Used when ``backend`` is ``"pyvista"``.
        wireframe: Draw edges without filled faces. Default: ``False``.
        show: Display the figure before returning. Default: ``True``. When
            this is ``False`` and Matplotlib created the figure, that figure
            is closed.
        save: Write the figure to disk. Default: ``False``.
        save_location: Directory for the saved figure. The working directory
            is used when omitted.
        save_name: File name. The extension is added from ``save_format`` when
            it is missing. Default: ``"mesh"``.
        save_format: File extension. Default: ``"pdf"``.
        dpi: Resolution used when saving. Default: ``300``.

    Returns:
        The Matplotlib axes, or the PyVista plotter.

    Raises:
        ValueError: If ``backend`` or ``dimensionality`` is unknown, if
            ``values`` is given without ``"point"`` or ``"cell"``, if
            ``values`` has the wrong length, if a face in ``surface_elements``
            is not an exterior face, or if a Matplotlib surface mixes face
            sizes.

    """
    surface, coloured_surface = _prepare_surface(
        mesh,
        cell_type,
        values=values,
        data_location=data_location,
        label=label,
        surface_elements=surface_elements,
    )

    kwargs = {
        "surface": surface,
        "coloured_surface": coloured_surface,
        "values_exist": values is not None,
        "label": label,
        "title": title,
        "dimensionality": dimensionality,
        "plane": plane,
        "cmap": cmap,
        "norm": norm,
        "boundaries": boundaries,
        "show_edges": show_edges,
        "wireframe": wireframe,
        "show": show,
        "save": save,
        "save_location": save_location,
        "save_name": save_name,
        "save_format": save_format,
        "dpi": dpi,
    }

    match backend.lower():
        case "matplotlib":
            return _plot_matplotlib(
                ax=ax,
                data_location=data_location,
                **kwargs,
            )

        case "pyvista":
            return _plot_pyvista(
                plotter=plotter,
                lighting=lighting,
                **kwargs,
            )

        case _:
            raise ValueError(f"Unknown plotting backend: {backend!r}")

    plot_stress(
    mesh: Mesh,
    stress,
    *,
    cell_type: CellType,
    component: Literal[
        "xx", "yy", "zz", "xy", "xz", "yz", "von_mises"

    Plot one component of a stress tensor on the mesh.

    stress has shape (n_elements, n_gauss, 3, 3), in Pascals. averaging="element" averages the Gauss points of each element and colors the cells. averaging="nodal" extrapolates the eight Gauss points of a Hex8 element to its nodes, averages values that meet at a node, and colors the nodes. Nodal averaging accepts only hexahedra with 2x2x2 Gauss quadrature.

    The plotted scalar is that component divided by stress_scale. The color label uses [Pa] when stress_scale is 1, and [-] otherwise. "von_mises" is:

    sqrt( 0.5 * ((sxx - syy) ** 2 + (syy - szz) ** 2 + (szz - sxx) ** 2) + 3 * (sxy ** 2 + sxz ** 2 + syz ** 2) )

    title=True uses that component label. title=False or None hides the figure title. A string sets a custom title.

    ``stress`` has shape ``(n_elements, n_gauss, 3, 3)``, in Pascals.
    ``averaging="element"`` averages the Gauss points of each element and
    colors the cells. ``averaging="nodal"`` extrapolates the eight Gauss
    points of a Hex8 element to its nodes, averages values that meet at a
    node, and colors the nodes. Nodal averaging accepts only hexahedra with

    hides the figure title. A string sets a custom title.

    Args:
        mesh: Tatva mesh to draw.
        stress: Gauss-point stress tensors, shaped
            ``(n_elements, n_gauss, 3, 3)``.
        cell_type: Cell shape of ``mesh``.
        component: ``"xx"``, ``"yy"``, ``"zz"``, ``"xy"``, ``"xz"``,
            ``"yz"``, or ``"von_mises"``. Default: ``"von_mises"``.
        averaging: ``"element"`` or ``"nodal"``. Default: ``"element"``.
        stress_scale: Divisor applied to the plotted values. Default: ``1``.
        title: ``True`` for the component label, ``False`` or ``None`` for no
            title, or a custom string. Default: ``True``.
        **plot_kwargs: Remaining keyword arguments of ``plot_mesh``, such as
            ``backend``, ``cmap``, and ``save``. ``values``,
            ``data_location``, ``label``, and ``title`` are set by this
            function.

    Returns:
        The Matplotlib axes, or the PyVista plotter.

    Raises:
        ValueError: If ``component`` or ``averaging`` is unknown, or if nodal
            averaging is requested for a mesh other than Hex8 with eight Gauss
            points.
        TypeError: If ``plot_kwargs`` repeats an argument this function passes
            itself, including ``cell_type``.

    """

        mesh,
        stress,
        cell_type=cell_type,
        component=component,
        averaging=averaging,
        stress_scale=stress_scale,
    )

    return plot_mesh(
        mesh,
        cell_type=cell_type,
        values=values,
        data_location=data_location,
        label=label,
        title=_resolved_title(title, label),
        **plot_kwargs,
    )

    def plot_mechanical_conditions(
    mesh: Mesh,
    conditions: MechanicalCondition | list[MechanicalCondition],
    *,
    cell_type: CellType,
    show_edges: bool = False,
    show: bool = True,
    save: bool = False,
    save_location: str | Path | None = None,
    save_name: str | None = None,
    save_format: str = "pdf",
    dpi: int = 300,
):
    """Draw each mechanical condition on a translucent copy of the mesh.

    Node conditions are spheres. Element conditions are colored patches. The
    legend uses the class name, so a ``Clamp`` is distinct from a ``Dirichlet``.

    Args:
        mesh: Tatva mesh to draw.
        conditions: One condition, or a list of them.
        cell_type: Cell shape of ``mesh``.
        show_edges: Draw element edges. Default: ``False``.
        show: Display the plotter before returning. Default: ``True``.
        save: Write the figure to disk. Default: ``False``.
        save_location: Directory for the saved figure.
        save_name: File name passed to the plot saver.
        save_format: File extension. Default: ``"pdf"``.
        dpi: Resolution used when saving. Default: ``300``.

    Returns:
        The PyVista plotter.

    """
    surface, _ = _prepare_surface(
        mesh,
        cell_type,
    )

    # plot light-grey mesh: # TODO: expand to work for matplotlib (as per fem.plot)
    plotter = pv.Plotter(off_screen=not show)
    plotter.add_mesh(
        surface,
        color="lightgray",
        opacity=0.25,
        show_edges=show_edges,
    )

    if not isinstance(conditions, list):
        conditions = [conditions]

    coords: np.ndarray = np.asarray(mesh.coords)
    legend_labels: set[str] = set()
    for condition in conditions:
        label = type(condition).__name__
        legend_label = label if label not in legend_labels else None

        color = CONDITION_COLORS.get(
            type(condition),
            CONDITION_COLORS[MechanicalCondition],
        )

        select = condition.elements(mesh, cell_type=cell_type)

        match condition.APPLICATION:
            case "element":
                patch = _select_surface_elements(surface, select)

                plotter.add_mesh(
                    patch,
                    color=color,
                    show_edges=show_edges,
                    lighting=False,
                    label=legend_label,
                )

            case "node":
                points: np.ndarray = coords[np.asarray(select)]

                plotter.add_points(
                    points,
                    color=color,
                    point_size=10,
                    render_points_as_spheres=True,
                    label=legend_label,
                )

        legend_labels.add(label)

    legend = cast(Any, plotter).add_legend(  # cast avoids ty error.
        loc="lower right",
        face="rectangle",
        font_family="courier",
    )

    legend.LockBorderOff()
    legend.GetEntryTextProperty().SetFontSize(11)
    cast(Any, plotter).add_axes(interactive=None)  # cast avoids ty error.

    if save:
        from pinnjax.plot import save_plot

        save_plot(
            plotter,
            save_location=save_location,
            save_name=save_name,
            save_format=save_format,
            dpi=dpi,
        )

    if show:
        plotter.show()
    return plotter

    def plot_sides(
    mesh: Mesh,
    *,
    cell_type: CellType,
    show_edges: bool = False,
    show: bool = True,
    save: bool = False,
    save_location: str | Path | None = None,
    save_name: str | None = None,
    save_format: str = "pdf",
    dpi: int = 300,
):
    """Color each exterior face of a mesh by its side name.

    Faces whose axis does not exist on this mesh are skipped. A 2D mesh does
    not draw ``"-z"`` or ``"+z"``.

    Args:
        mesh: Tatva mesh to draw.
        cell_type: Cell shape of ``mesh``.
        show_edges: Draw element edges. Default: ``False``.
        show: Display the plotter before returning. Default: ``True``.
        save: Write the figure to disk. Default: ``False``.
        save_location: Directory for the saved figure.
        save_name: File name passed to the plot saver.
        save_format: File extension. Default: ``"pdf"``.
        dpi: Resolution used when saving. Default: ``300``.

    Returns:
        The PyVista plotter.

    """
    surface, _ = _prepare_surface(mesh, cell_type)

    plotter = pv.Plotter(off_screen=not show)

    dim = mesh.coords.shape[1]

    for side, (axis, _) in SIDE_AXIS_SIGN.items():
        if axis >= dim:
            continue

        elements = select_boundary(
            mesh,
            cell_type=cell_type,
            application="element",
            location=None,
            side=side,
        )

        patch = _select_surface_elements(surface, elements)

        plotter.add_mesh(
            patch,
            color=SIDE_COLORS[side],
            show_edges=show_edges,
            label=side,
            lighting=False,
        )

    legend = cast(Any, plotter).add_legend(  # cast avoids ty error.
        loc="lower right",
        face="rectangle",
        font_family="courier",
    )
    legend.LockBorderOff()
    legend.GetEntryTextProperty().SetFontSize(11)

    cast(Any, plotter).add_axes(  # cast avoids ty error.
        interactive=None,
        x_color="k",
        y_color="k",
        z_color="k",
    )

    if save:
        from pinnjax.plot import save_plot

        save_plot(
            plotter,
            save_location=save_location,
            save_name=save_name,
            save_format=save_format,
            dpi=dpi,
        )

    if show:
        plotter.show()

    return plotter
