    HardValueConstraint #

    Bases: HardConstraint

    Analytical hard constraint with a prescribed value and a vanishing factor.

    The constrained output is value + factor * (output - value). - value is the prescribed field. - factoris zero on the constrained manifold and approaches 1 away from it.

    HardScalarInitialConstraint, HardArrayInitialConstraint, and HardDirichletConstraint use this form. DirichletHardConstraintOnMesh does not. It replaces selected nodal components and remains a HardConstraint.

    A tuple of compatible instances passed as Optimization.hard_constraint is combined when the network is built. The combined constraint replaces those instances at the position of the first one. A HardConstraint that is not a HardValueConstraint stays where it was written and runs as its own step. The prescribed field is the initial condition when one is present, and every factor is multiplied. That product is divided by its maximum on the domain, so the blend reaches 1 there and stays 0 on each manifold. The output matches every prescribed value on those manifolds only when the values agree where the manifolds meet.

    class HardValueConstraint(HardConstraint):
    """Analytical hard constraint with a prescribed value and a vanishing factor.

    The constrained output is ``value + factor * (output - value)``.
    - `value` is the prescribed field.
    - `factor`is zero on the constrained manifold and approaches 1 away from it.

    [`HardScalarInitialConstraint`][pinnjax.HardScalarInitialConstraint],
    [`HardArrayInitialConstraint`][pinnjax.HardArrayInitialConstraint], and
    [`HardDirichletConstraint`][pinnjax.HardDirichletConstraint] use this form.
    [`DirichletHardConstraintOnMesh`][pinnjax.DirichletHardConstraintOnMesh]
    does not. It replaces selected nodal components and remains a
    [`HardConstraint`][pinnjax.HardConstraint].

    [`Optimization.hard_constraint`][pinnjax.Optimization] is combined when the

    class HardScalarInitialConstraint(HardValueConstraint):
    """Hard initial condition specified by a scalar or 1D value.

    The constrained output is ``ic + phi * (output - ic)``, where
    ``phi = 1 - exp(-(t - times.min) / tau)`` and ``t`` is the evolution
    coordinate. ``tau`` is ``-times.range() / log(0.05)``. A zero range is
    replaced by ``config.get_EPS()``. At ``t = times.min`` the result is the
    initial condition. At ``t = times.max`` the result is 95% network output.

    Args:
        times: [`Time`][pinnjax.dataclass.time.Time] whose range sets ``tau``.
        initial_condition: Scalar, or a tuple of length 1 or the output width.
            Stored with ``config.get_dtype()``.
        evolution_axis: Index of the time component in one point. ``-1`` is the last component.
            Default: ``-1``.

    Attributes:
        times: The stored [`Time`][pinnjax.dataclass.time.Time].
        initial_condition: Initial value as an array.
        evolution_axis: Index passed to the evolution-coordinate lookup.
        tau: Time scale of the blend.

    """

    def __init__(
        self,
        times: Time,
        initial_condition: float | tuple,
        evolution_axis: int = -1,
    ):
        """Store the initial value and the blend time scale."""
        self.times = times
        self.initial_condition = jnp.asarray(
            initial_condition,
            dtype=config.get_dtype(),
        )
        self.evolution_axis = evolution_axis

        phi95 = jnp.asarray(0.95, dtype=config.get_dtype())
        rng = jnp.asarray(self.times.range(), dtype=config.get_dtype())
        rng = jnp.where(jnp.abs(rng) < config.get_EPS(), config.get_EPS(), rng)
        self.tau = jnp.asarray(-rng / jnp.log1p(-phi95), dtype=config.get_dtype())

    def __call__(self, inputs, output):
        """Apply the constraint to one point or a batch.

        A one-dimensional ``inputs`` is one point. The output is squeezed, constrained,
        and expanded to at least one dimension. A batch is mapped over axis 0.
        A one-dimensional batch result gains a trailing axis, so scalar outputs have shape ``(N, 1)``.

        Args:
            inputs: One point, or a batch of points.
            output: Network output for those points.

        Returns:
            The constrained output.

        """
        if inputs.ndim == 1:
            val = self.point(inputs, jnp.squeeze(output))
            return jnp.atleast_1d(val)
        # multiple inputs
        fn = jax.vmap(self.point, in_axes=(0, 0))
        batched = fn(inputs, output)

        return batched[:, None] if batched.ndim == 1 else batched

    def value(self, inputs, output):
        """Return the initial condition.

        Args:
            inputs: Unused. The stored value does not depend on the point.
            output: Network output. Supplies the dtype.

        Returns:
            ``initial_condition`` cast to ``output.dtype``.

        """
        return jnp.asarray(self.initial_condition, dtype=output.dtype)

    def factor(self, inputs):
        """Return the time blend, zero at ``times.min``.

        Args:
            inputs: One point. The evolution component is the entry at
                ``evolution_axis``.

        Returns:
            ``1 - exp(-(t - times.min) / tau)``.

        """
        t = _evolution_coordinate(inputs, self.evolution_axis)
        tmin = jnp.asarray(self.times.min, dtype=inputs.dtype)
        tau = self.tau.astype(inputs.dtype)
        return jnp.asarray(1.0, dtype=inputs.dtype) - jnp.exp(-(t - tmin) / tau)

    def point(self, inputs: jnp.ndarray, output: jnp.ndarray):
        """Apply the constraint at one point.

        Args:
            inputs: One point.
            output: Network output at that point. A scalar may be zero-dimensional.

        Returns:
            ``ic + phi * (output - ic)``.

        Raises:
            ValueError: If ``initial_condition`` has more than one dimension,
                if a scalar output is paired with an initial condition longer than 1, or if a
                one-dimensional initial condition has a length other than 1 or the output width.

        """
        ic = self.value(inputs, output)
        phi = self.factor(inputs)

        # --- validate initial_condition vs output ---
        if ic.ndim > 1:
            msg = f"initial_condition must be scalar or 1D, got shape {ic.shape}"
            config.LOGGER.error(msg)
            raise ValueError(msg)
        if output.ndim == 0:
            if ic.ndim == 1 and ic.size != 1:
                msg = (
                    f"Scalar output but initial_condition has size {ic.size} - "
                    f"Consider using 'HardArrayInitialConstraint instead."
                )
                config.LOGGER.error(msg)
                raise ValueError(msg)
        else:
            C = output.shape[-1]
            if ic.ndim == 1 and ic.size not in (1, C):
                msg = f"initial_condition length {ic.size} does not match outputs {C}."
                config.LOGGER.error(msg)
                raise ValueError(msg)
        # ---------------------------------------------

        return ic + phi * (output - ic)

    class HardArrayInitialConstraint(HardValueConstraint):
    """Hard initial condition specified by an array or array-valued callable.

    The blend matches
    [`HardScalarInitialConstraint`][pinnjax.HardScalarInitialConstraint]:
    ``ic + phi * (output - ic)``, with
    ``phi = 1 - exp(-(t - times.min) / tau)``. ``tau``
    is ``-times.range() / log(0.05)``. A zero range is replaced by
    ``config.get_EPS()``. At ``t = times.min`` the result is the initial
    condition. At ``t = times.max`` the result is 95% network output. A callable
    initial condition is evaluated at the point. A fixed array is the value for
    one point, and its shape must equal the output shape at that point.

    Args:
        times: [`Time`][pinnjax.Time] whose range sets ``tau``.
        initial_condition: Array for one point, or a callable from that
            point's inputs to an array of the same shape as the output.
        evolution_axis: Index of the time component. Default: ``-1``.

    Attributes:
        times: The stored [`Time`][pinnjax.Time].
        initial_condition: The array or callable.
        evolution_axis: Index passed to the evolution-coordinate lookup.
        tau: Time scale of the blend.

    """

    def __init__(
        self,
        times: Time,
        initial_condition: jnp.ndarray | Callable[[jnp.ndarray], jnp.ndarray],
        evolution_axis: int = -1,
    ) -> None:
        """Store the initial condition and the blend timescale."""
        self.times = times
        self.initial_condition = initial_condition
        self.evolution_axis = evolution_axis

        phi95 = jnp.asarray(0.95, dtype=config.get_dtype())
        rng = jnp.asarray(self.times.range(), dtype=config.get_dtype())
        rng = jnp.where(jnp.abs(rng) < config.get_EPS(), config.get_EPS(), rng)
        self.tau = jnp.asarray(-rng / jnp.log1p(-phi95), dtype=config.get_dtype())

    def __call__(self, inputs, output):
        """Apply the constraint to one point or a batch.

        A one-dimensional ``inputs`` is one point. The output is squeezed,
        constrained, and expanded to at least one dimension. A batch is
        mapped over axis 0, and the result keeps the mapped shape.

        Args:
            inputs: One point, or a batch of points.
            output: Network output for those points.

        Returns:
            The constrained output.

        """
        if inputs.ndim == 1:
            return jnp.atleast_1d(self.point(inputs, jnp.squeeze(output)))
        fn = jax.vmap(self.point, in_axes=(0, 0))
        return fn(inputs, output)

    def value(self, inputs, output):
        """Return the initial condition at one point.

        A callable specification is evaluated at ``inputs``. A fixed array is
        returned unchanged except for its dtype.

        Args:
            inputs: One point. Passed to a callable initial condition.
            output: Network output. Supplies the dtype.

        Returns:
            The initial condition cast to ``output.dtype``.

        """
        ic_spec = self.initial_condition
        if callable(ic_spec):
            ic = cast("Callable[[jnp.ndarray], jnp.ndarray]", ic_spec)(inputs)
        else:
            ic = ic_spec
        return jnp.asarray(ic, dtype=output.dtype)

    def factor(self, inputs):
        """Return the time blend, zero at ``times.min``.

        Args:
            inputs: One point. The evolution component is the entry at
                ``evolution_axis``.

        Returns:
            ``1 - exp(-(t - times.min) / tau)``.

        """
        t = _evolution_coordinate(inputs, self.evolution_axis)
        tmin = jnp.asarray(self.times.min, dtype=inputs.dtype)
        tau = self.tau.astype(inputs.dtype)
        return jnp.asarray(1.0, dtype=inputs.dtype) - jnp.exp(-(t - tmin) / tau)

    def point(self, inputs: jnp.ndarray, output: jnp.ndarray):
        """Apply the constraint at one point.

        Args:
            inputs: One point. Passed to a callable initial condition.
            output: Network output at that point.

        Returns:
            ``ic + phi * (output - ic)``.

        Raises:
            ValueError: If the initial-condition shape differs from
                ``output.shape``.

        """
        ic = self.value(inputs, output)
        phi = self.factor(inputs)

        if ic.shape != output.shape:
            msg = f"IC shape {ic.shape} != output shape {output.shape}"
            config.LOGGER.error(msg)
            raise ValueError(msg)

        return ic + phi * (output - ic)

    class HardDirichletConstraint(HardValueConstraint):
    """Hard Dirichlet value on one coordinate side.

    The blend has the same form as
    [`HardScalarInitialConstraint`][pinnjax.HardScalarInitialConstraint]:
    ``bc + phi * (output - bc)``, with ``phi = 1 - exp(-distance / tau)``.
    ``tau`` comes from ``domain.range`` on the selected axis. A zero range is
    replaced by ``config.get_EPS()``.

    ``distance`` is measured inward from the requested side of
    [`Domain`][pinnjax.Domain]. A negative entry of ``side`` is the minimum
    face, ``inputs[idx] - domain.min[idx]``. A positive entry is the maximum
    face, ``domain.max[idx] - inputs[idx]``. The value is exact on that face.

    Args:
        domain: [`Domain`][pinnjax.Domain]. ``range`` on the selected axis sets ``tau``.
        condition: Boundary value.
        side: One side marker, such as ``(-1,)`` or ``(0, 0, 1)``. Exactly one
            entry is nonzero. Its index is the axis and its sign selects the face.

    Attributes:
        domain: The stored domain.
        min: Copy of ``domain.min``.
        max: Copy of ``domain.max``.
        condition: Boundary value as an array.
        idx: Axis taken from ``side``.
        sign: ``1`` for the maximum face and ``-1`` for the minimum face.
        tau: Length scale of the blend.

    """

    def __init__(
        self,
        domain: Domain,  # .min, .max
        condition: float,
        side: tuple[int, ...] | list[int],
    ) -> None:
        """Store the boundary value, the selected face, and the blend length scale.

        Raises:
            ValueError: If ``side`` does not contain exactly one nonzero number.

        """
        self.domain = domain
        self.min = jnp.asarray(domain.min, dtype=config.get_dtype())
        self.max = jnp.asarray(domain.max, dtype=config.get_dtype())
        self.condition = jnp.asarray(condition, dtype=config.get_dtype())

        nonzero = [(i, component) for i, component in enumerate(side) if component]
        if len(nonzero) != 1:
            msg = f"side must contain exactly one nonzero coordinate direction, got {side}."
            config.LOGGER.error(msg)
            raise ValueError(msg)
        self.idx, component = nonzero[0]
        try:
            component_value = float(component)
        except (TypeError, ValueError) as exc:
            msg = f"side entry must be a real number, got {component!r}."
            config.LOGGER.error(msg)
            raise ValueError(msg) from exc
        self.sign = 1 if component_value > 0 else -1
        rng = jnp.asarray(domain.range(self.idx), dtype=config.get_dtype())
        rng = jnp.where(jnp.abs(rng) < config.get_EPS(), config.get_EPS(), rng)
        phi95 = jnp.asarray(0.95, dtype=config.get_dtype())
        self.tau = jnp.asarray(-rng / jnp.log1p(-phi95), dtype=config.get_dtype())

    def __call__(self, inputs, output):
        """Apply the constraint to one point or a batch.

        A one-dimensional ``inputs`` is one point. The output is squeezed,
        constrained, and expanded to at least one dimension. A batch is mapped
        over axis 0. A one-dimensional batch result gains a trailing axis, so
        scalar outputs have shape ``(N, 1)``. This matches
        [`HardScalarInitialConstraint`][pinnjax.HardScalarInitialConstraint].

        Args:
            inputs: One point, or a batch of points.
            output: Network output for those points.

        Returns:
            The constrained output.

        """
        if inputs.ndim == 1:
            return jnp.atleast_1d(self.point(inputs, jnp.squeeze(output)))
        fn = jax.vmap(self.point, in_axes=(0, 0))
        batched = fn(inputs, output)
        return batched[:, None] if batched.ndim == 1 else batched

    def value(self, inputs, output):
        """Return the Dirichlet value.

        Args:
            inputs: Unused. The stored condition does not depend on the point.
            output: Network output. Supplies the dtype.

        Returns:
            ``condition`` cast to ``output.dtype``.

        """
        return jnp.asarray(self.condition, dtype=output.dtype)

    def factor(self, inputs):
        """Return the spatial blend, zero on the selected face.

        Args:
            inputs: One point.

        Returns:
            ``1 - exp(-distance / tau)``. ``distance`` is zero at
            ``domain.min[idx]`` when ``sign`` is negative, and at
            ``domain.max[idx]`` when ``sign`` is positive.

        """
        if self.sign < 0:
            distance = inputs[self.idx] - self.min[self.idx].astype(inputs.dtype)
        else:
            distance = self.max[self.idx].astype(inputs.dtype) - inputs[self.idx]
        tau = self.tau.astype(inputs.dtype)
        return jnp.asarray(1.0, dtype=inputs.dtype) - jnp.exp(-distance / tau)

    def point(self, inputs: jnp.ndarray, output: jnp.ndarray):
        """Apply the constraint at one point.

        Args:
            inputs: One point.
            output: Network output at that point.

        Returns:
            ``bc + phi * (output - bc)``.

        """
        bc = self.value(inputs, output)
        phi = self.factor(inputs)
        return bc + phi * (output - bc)

    class DirichletHardConstraintOnMesh(HardConstraint):
    """Hard Dirichlet displacement on selected mesh nodes.

    Node indices come from [`Dirichlet`][pinnjax.fem.Dirichlet] ``elements``.
    Selected components of those nodes are replaced by ``condition.value``.
    Every other entry of ``output`` stays as evaluated. ``"x"``, ``"y"``, and
    ``"z"`` are the first three columns.

    Args:
        mesh: Tatva mesh. The node count is ``mesh.coords.shape[0]``.
        condition: Nodal Dirichlet condition. ``value`` is stored as a float.
        cell_type: Cell shape passed to ``condition.elements``.

    Attributes:
        node_mask: One entry per mesh node. Selected nodes are ``1``.
        component_mask: Length 3. Selected components are ``1``.
        value: Prescribed displacement.

    """

    def __init__(
        self,
        mesh: Mesh,
        condition: pinnjax.fem.Dirichlet,
        *,
        cell_type: CellType,
    ) -> None:
        """Store the node mask, the component mask, and the prescribed value.

        Raises:
            KeyError: If a component is not ``"x"``, ``"y"``, or ``"z"``.

        """
        nodes = np.asarray(
            condition.elements(mesh, cell_type=cell_type),
            dtype=np.int32,
        )

        component_indices = {
            "x": 0,
            "y": 1,
            "z": 2,
        }

        node_mask = np.zeros(mesh.coords.shape[0], dtype=np.float64)
        node_mask[nodes] = 1.0

        component_mask = np.zeros(3, dtype=np.float64)
        for component in condition.components:
            component_mask[component_indices[component]] = 1.0

        self.node_mask = jnp.asarray(node_mask, dtype=config.get_dtype())
        self.component_mask = jnp.asarray(component_mask, dtype=config.get_dtype())
        self.value = float(condition.value)

    def __call__(self, inputs: Array, output: Array) -> Array:
        """Replace the selected node components.

        Only ``inputs.shape[0]`` is used. ``output`` is combined with a mask
        of shape ``(n_nodes, 3)``.

        Args:
            inputs: One row per mesh node.
            output: Network output. The last axis is the ``x``, ``y``, and
                ``z`` components.

        Returns:
            ``output`` with the selected entries set to ``value``.

        Raises:
            ValueError: If ``inputs.shape[0]`` is not the mesh node count.

        """
        if inputs.shape[0] != self.node_mask.shape[0]:
            raise ValueError(
                f"Expected {self.node_mask.shape[0]} mesh nodes, got {inputs.shape[0]}.",
            )

        mask = self.node_mask[:, None] * self.component_mask[None, :]
        return output * (1.0 - mask) + self.value * mask
