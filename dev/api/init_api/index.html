    PINN-JAX: Physics-Informed Neural Networks for JAX.#

    This package provides tools for defining, training, and evaluating physics-informed neural networks (PINNs) in Python using JAX.

    Modules included:

    • config: Global constants and configuration parameters.
    • dataclass: Structured definitions for activations, paths, domains, materials, optimization, and training configurations.
    • experiment: ExperimentBuilder for managing and running PINN experiments.
    • geometry: Geometric primitives and domain shapes.
    • grid: Grid generation and comparison utilities.
    • importance: Sensitivity analysis tools, including MorrisMethod.
    • loss: Loss function definitions for boundary conditions, PDE residuals, and regularization.
    • model: Neural network architectures, constraints, transformations, and utilities.
    • pathing: Path definitions and generators for trajectories in the domain.
    • plot: Visualization functions for predictions, losses, and evolutions.
    • predict: Functions for predicting at times or along paths.
    • sampling: Sampling methods for domain points, e.g., SobolSampler.
    • storage: Model saving and loading utilities.
    • train: Training routines for PINNs.
    • utils: Helper functions for folder creation, path management, duration conversion, and other utilities.
