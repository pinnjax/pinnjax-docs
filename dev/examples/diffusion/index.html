    Diffusion

    The full runnable script can be found at examples/public/diffusion.py on GitHub.

    It trains a 1D diffusion problem on \([-1, 1]\) from \(t = 0\) to \(t = 1\), with defaults:

    • diffusion coefficient: \(0.25\) and
    • mode: \(5\).

    Feel free to experiment with different values.

    \[ u_t = D u_{xx}, \quad u(x, 0) = \sin\left(\frac{n\pi}{2}(x + 1)\right), \quad u(\pm 1, t) = 0. \]

    SAVE, PLOT, and SHOW at the top of the script control the model folder, the loss plot, and the comparison animation.

    Domain#

    step is used for sampling. A problem with no time uses times=None. to_obb() turns the domain into the origin and edge used by the line geometry.

    time = pinnjax.Time(min=0, max=1, step=0.1)  # from 0s to 1s with a 0.1s time-step
# the time-step is used exclusively for sampling.
domain = pinnjax.SpatialDomain(min=(-1,), max=(1,), times=time)  # [-1, 1] m + time
# if the problem isn't time-dependent use times=None

# PINN-JAX defines Shapes using OBBs (Oriented Bounded Boxes)
# You could define your own OBB using an Origin point and Edges
# (dependent on the dimensionality of the domain)
# To save time, a SpatialDomain can be converted into an OBB.
origin, end = domain.to_obb()

# since domain is 1D, obb is defined as an origin and 1 edge - [origin, edge]

    Model#

    Inputs are scaled to \([-1, 1]\). The initial condition is a hard constraint, so the network output is forced to that sine at \(t = 0\). The network takes \((x, t)\) and returns \(u\).

    def initial_condition_fn(pt):
    # pt[0] is x, pt[-1] is t
    return jnp.sin(mode * (jnp.pi / 2) * (pt[0] + 1))

# Hard Constraint on the Initial Condition
hard_ic = pinnjax.HardArrayInitialConstraint(times=time,
                                             initial_condition=initial_condition_fn)

# Define the Optimization Object
optimization = pinnjax.Optimization(
    input_transformation=pinnjax.NormalizationBetweenNeg1and1(domain=domain),
    # Input Transformations
    output_transformation=None,  # Output Transformations
    hard_constraint=(hard_ic,),  # Hard Constraints
)
# Multiple Hard Constraints can be added as a Tuple, the constraints will be applied
# in order. At this time, you cannot have multiple input/output transformations. If
# you have no such 'Optimizations' you can leave all 3 as None, or set
# optimization=None

# Define the topology (specific to FNN) [input, layer .... layer, output]
topology = (2, 8, 8, 8, 8, 1)  # [input: x, t] [output: u]

# Define the Activation Object. Currently, all interior layers get the same activation.
activation = pinnjax.Activation(jax.nn.tanh)
# Look at the jax.nn documentation for available options.
# If the selected option has kwargs or args:
# activation = pinnjax.Activation(jax.nn.gelu, kwargs={"approximate": False})

# Note: The Dataclasses are all well-documented, therefore all of this information
# is already in the documentation provided.

# Initialize the Model  - Note currently the only option is FNN, but you are free to
# attempt to make your own by defining a new NeuralNetwork class.
model = pinnjax.FNN(
    domain,
    topology,
    activation,
    optimization=optimization,  # optional parameter defaults to None
    initialization=None,
)  # optional parameter defaults to None

    Hard constraints are a tuple and run in order. One input transformation and one output transformation are supported. Leave an entry as None when you do not need it.

    Geometry#

    BoundedLine builds the interior segment and its two endpoints. initial=True appends the same segment at the first time. That initial line is optional once the hard constraint is in place. The script draws it so those points stay in the training loss.

    geometry: ComplexShape = pinnjax.BoundedLine(
    (float(origin[0]),),
    (float(end[0]),),
    times=time,
    initial=True,
)
# Other options include BoundedBox (3D) and Bounded Rectangle (2D), or you can make
# your own pinnjax.ComplexShape() class, though naturally you'll have to write all
# additional features.

# *obb opens up the [obb edge] list initial=True means a shape will be added to the
# ComplexShape only at t=0. if you forget to add this initial shape, it can be added
# later with: geometry.add_initial() Since we are hard constraining our initial
# conditions, this isn't strictly necessary, but showing the model initial points
# during training has been shown to increase stability.

    A 2D problem uses BoundedRectangle. A 3D problem uses BoundedBox.

    Sampling#

    A time-dependent BoundedLine contains FOUR interior primitive Shapes:

    • A temporal Line, two Dot, and an initial Line.

    We need to sample points within all of these shapes. Currently, the only SamplingMethod is the SobolSequencer so we use that here, but feel free to write your own. 

    method = pinnjax.SobolSampler(mode="point_count")

npoints = [1000, 1, 1, 10]

# Sample:
geometry.sample(method, npoints)

# Optional: Check Your Work
# geometry.draw(show_samples=True)
# setting show_samples=True only works after sampling.

    Residuals#

    The PDE residual is \(u_t - D u_{xx}\). Each boundary residual is the predicted value, which is the homogeneous Dirichlet condition. The initial residual repeats the sine. It is a check. The hard constraint already enforces that condition.

    # Make a subclass of pinnjax.PartialDifferentialEquation
class Diffusion(pinnjax.PartialDifferentialEquation):
    # define:
    #     an __init__,
    #     a _residual (one point at a time),
    #     a _residuals() (vmapped)
    #     and an @eqx.filter_jit __call__()

    # the _residual, _residuals, and __call__ must have the same inputs as here.
    def __init__(self, diffusion_coeff: float = 1e-3):
        self.diffusion_coeff = diffusion_coeff

    def _residual(self, u: Array, ops: pinnjax.DifferentialOperators) -> Array:
        u_t = ops.evolution_derivative(u)
        u_xx = ops.laplacian(u)  # in 1D this is d^2 u / dx^2
        return u_t - self.diffusion_coeff * u_xx

    def _residuals(self,
                   points: Array, ops: pinnjax.DifferentialOperators
                   ) -> Array:
        vm = jax.vmap(lambda p: self._residual(p, ops), in_axes=0)
        return jnp.nan_to_num(vm(points), nan=1e-6, posinf=1e6, neginf=-1e6)

    @eqx.filter_jit
    def __call__(self,
                 points: Array,
                 ops: pinnjax.DifferentialOperators
                 ) -> Array:
        return self._residuals(points, ops)

# 5b. BC
class DiffusionBC(pinnjax.BoundaryCondition):
    # same deal here, but for a subclass of pinnjax.BoundaryCondition
    def __init__(self):
        super().__init__()

    def _residual(self,
                  points: Array, ops: pinnjax.DifferentialOperators
                  ) -> Array:
        u_val = ops.T(points)
        return u_val

    def _residuals(self,
                   points: Array, ops: pinnjax.DifferentialOperators
                   ) -> Array:
        vm = jax.vmap(lambda p: self._residual(p, ops), in_axes=0)
        return jnp.nan_to_num(vm(points), nan=1e-6, posinf=1e6, neginf=-1e6)

    @eqx.filter_jit
    def __call__(self,
                 points: Array, ops: pinnjax.DifferentialOperators
                 ) -> Array:
        return self._residuals(points, ops)

# 5c. IC
# Since we are hard constraining our Initial Conditions this isn't strictly necessary,
# but it helps to make sure it's working.
class DiffusionIC(pinnjax.InitialCondition):
    # This particular class utilizes the predefined functions of the parent
    # InitialCondition class but in effect it has the same format as the other 2
    # types. Functionally, all 3 (PDE, BC, IC) are identical in function, but they
    # are separated for the purpose of weighted loss functions, and adaptive weights.
    def __init__(self):
        super().__init__(lambda pt: jnp.sin(mode * (jnp.pi / 2) * (pt[0] + 1)))

    Assign one residual per shape, in the same order as the sample counts. Every shape uses residual mean squared error.

    initial_condition = DiffusionIC()
boundary_condition = DiffusionBC()
pde = Diffusion(diffusion_coefficient)

# Assign the Residuals to the shape.
# Again here you need to remember the number of shapes you have, and their order.
residuals: list[pinnjax.Residual] = [
    pde,
    boundary_condition,
    boundary_condition,
    initial_condition,
]
# Assign them:
geometry.assign_residuals(residuals)

# Assign the Loss function - Currently, all shapes get the same Loss
# if you wish to have unique losses, you can loop through the shapes:
# for shape, loss in zip(geometry.shapes, losses):
#   # and assign them individually
#   shape.set_loss(loss)

geometry.assign_loss(pinnjax.ResidualMSError())
# here we use the Residual MSE, but are free to define your own pinnjax.Loss()

    A second PDE on the same segment needs another shape. One shape carries one residual.

    Training#

    Adam uses an exponential decay from \(10^{-2}\) to \(10^{-5}\). train_mode="class" groups the loss as PDE, boundary, and initial. Early stopping waits 500 epochs for a relative improvement of \(10^{-4}\).

    scheduler = optax.exponential_decay(
    init_value=1e-2,
    transition_steps=100,  # decay every 100 epochs
    decay_rate=0.95,  # 5% reduction each time
    end_value=1e-5,  # don't go below this
)

# Define the Optimizer - This functions the same as Activation, where kwargs and args
# can be added. Look at optax documentation for options.
optimizer = pinnjax.Optimizer(
    optax.lion,
    kwargs={"learning_rate": scheduler, "b1": 0.9, "b2": 0.999},
)

training = pinnjax.Training(
    optimizer,
    epochs=20000,  # set the number of epochs
    # everything after here is optional and has a default value.
    use_adaptive_weights=False,
    # automatically update the weighting of the
    # multi-objective loss function
    adaptive_alpha=0.9,
    # how much of current weights effects new calculation.
    update_weights_every=1000,  # how often to update weights
    update_weights_after=250,
    # when to start updating weights (starting very early is
    # unstable)
    train_mode="class",  # type or class type divides the
    # losses (for the purpose of adaptive weights) into
    # Diffusion, pde2, DiffusionBC, bc2, etc... class divides
    # into PDE, BC, IC
    balance_magnitudes=False,
    # since the expected residual loss of one residual might
    # be very different from another this aims to allow the
    # model to learn all objectives, by pulling the losses
    # closer in magnitude.
    magnitude_clip=1e-2,
    # limit of how much the loss can be modified.
    early_stopping=True,
    # if loss has converged, whether to stop training early.
    rel_tolerance=0.0001,
    # compared to the current best model, how much better
    # is the new model (relatively)
    patience=500,
    # how many epochs without improvement (better than
    # the relative tolerance) before stopping
)
setup_time = timer.perf_counter() - tstart
tstart = timer.perf_counter()
updated_model = pinnjax.train(
    model,
    geometry,
    training,
    verbosity=500,  # how often (in epochs) to print the results (loss).
    print_mode="class",  # same as train_mode but for the print.
)

    With SAVE true, the script writes the model, a JSON config, and the log under a new Diffusion run folder.

    Prediction#

    A LineGrid is the evaluation mesh. The reference solution is the exact decay of the initial sine:

    \[ u(x, t) = \exp\left(-\left(\frac{n\pi}{2}\right)^2 D t\right) \sin\left(\frac{n\pi}{2}(x + 1)\right). \]
    grid = pinnjax.LineGrid(
    domain=domain, axis="x", num_points=100, time_range=(0, 1), num_times=100
)
# inputs should be self-explanatory.

def analytic_solution(_x, t, _mode=1, D=1e-3):
    """Analytical solution for IC.

    u(x,0)=sin(pi/2 * (x+1)), domain [-1,1], Dirichlet BC:
    u(x,t) = exp(- (pi/2)^2 * D * t) * sin(pi/2 * (x+1))
    """
    k = _mode * (np.pi / 2)
    return np.exp(-(k ** 2) * D * t) * np.sin(k * (_x + 1))


# prebuilt function that predicts the spatial-temporal points for the given model
# and grid another option includes predict() which is for a single timestep.
# predict_evolution is a wrapper around that function which loops through the
# time-steps of the Grid.
preds = pinnjax.predict_evolution(_model, _grid)  # shape: (num_times, num_points)

    Inside the animation, predict_evolution is called with the trained model and this grid. It returns one field per time. The script animates that field against the reference and saves diffusion.gif when SAVE is true. geometry.plot_loss() writes the loss curves for the same run.
